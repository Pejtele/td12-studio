TD-12 Trigger Editor

Edit the trigger settings of a Roland TD-12 from your computer, without its screen. Independent project, not affiliated with Roland. Works in Chrome or Edge (Web MIDI). Settings manual

1 · Connect

Both MIDI cables: interface OUT → TD-12 MIDI IN, and TD-12 MIDI OUT/THRU → interface IN.

Not connected.

2 · Read from the TD-12

On the module press: SETUP → F1 (MIDI) → F5 (BULK) → choose ALL TRIG BANKS → F5 (EXECUTE).

With an unreadable screen: SETUP → F1 → F5, then turn the dial left 20–30 clicks (this always lands on the first option, ALL), then right exactly 4 clicks (SETUP, ALL DRUM KITS, 1 DRUM KIT, ALL TRIG BANKS), then F5. If something else arrives, this page says what it was. ALL also works, it just takes a few minutes. A dump only sends data; it changes nothing on the module.

Safety

  1. Only the selected bank is sent. Every other byte of it is kept exactly as read.
  2. Before the first send, a backup of the read is downloaded. Keep it.
  3. After sending, dump again: the page checks the module byte for byte.
  4. Writing is enabled only for module versions already verified on real hardware (revision 00 02 00 00). Other versions can read and download backups; please report them.

This page counts visits and anonymous events (connected, dump read, send verified or failed, module revision) with GoatCounter, without cookies. Your trigger settings and backups never leave your computer.
